# Bugs

Defects found while working this project that are not themselves a tracked story.

One file per bug: `YYYY-MM-DD-short-slug.md`, recording the symptom, the
reproduction, what was ruled out, and the current status. Once a bug gets a
ticket and a story folder, leave a pointer here rather than duplicating it.

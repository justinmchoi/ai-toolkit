# Teaching

Material written to hand to someone else — an onboarding pack, a walkthrough, an
explainer with a reading order.

**Numbered**, `NN-kebab-slug.md`, and `00-start-here.md` is the entry file: a
table of what each file gives you, a 60-second summary, and the two or three
mental models that make the rest click. A reader who stops after `00` should
still be net ahead. This numbering is a deliberate exception to plain kebab-case,
alongside `DecisionRecords/` — a teaching set has a load-bearing sequence.

End each file with four or five "you should now be able to answer…" questions.
Writing them is what exposes a section that explained a mechanism without
conveying when it matters.

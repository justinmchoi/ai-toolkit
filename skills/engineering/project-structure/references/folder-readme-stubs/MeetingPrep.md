# Meeting Prep

Agendas, question lists, and pre-reads written *before* a meeting, plus the notes
taken during it.

One file per meeting: `YYYY-MM-DD-who-or-topic.md`.

Not for decisions that came out of a meeting — those go to `DecisionRecords/`
once their relevance outlives the meeting, or to the story folder they belong to
if it does not.

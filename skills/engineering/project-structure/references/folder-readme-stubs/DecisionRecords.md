# Decision Records

Architecture and design decisions whose relevance outlives the single story
folder that produced them. One file per genuinely independent decision.

`000N-kebab-slug.md`, sequentially numbered, with this README as the index. The
number is load-bearing — creation order matters — so this folder is a deliberate
exception to the project's plain-kebab-case file convention.

A decision scoped tightly enough to matter only within one story is fine staying
in that story folder. This folder is for the ones that do not stay scoped.
